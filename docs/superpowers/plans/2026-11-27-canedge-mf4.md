# Compiled CANedge MF4 reader — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the `mdf-iter` plus pandas body of `read_mf4_file` with `canedge-mf4`, a C++ program that reads one unfinalized CANedge `.MF4` or heatshrink `.MFC` and writes an Arrow IPC stream of `FRAME_SCHEMA`.

**Architecture:** `packages/canedge-cyphal` builds `canedge-mf4`. It unwraps `.MFC`, scans one unfinalized `##DT`, emits data frames and SocketCAN error frames, and stably sorts them. `read_mf4_file` runs the program. `read_mf4_file_pandas` remains for the speed test only. `convert_one` is unchanged apart from the reader it already calls.

**Tech Stack:** C++17, C11, Apache Arrow IPC, vendored heatshrink 0.4.1, GoogleTest, Python 3.10+, pyarrow, pytest. `mdf-iter` and pandas stay dev dependencies for the speed test.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-11-27-canedge-mf4-design.md`
- Program name is `canedge-mf4`. One filesystem path in. Arrow IPC stream (not the file format) of `FRAME_SCHEMA` on stdout. One `error: ...` line on stderr. Non-zero exit writes no IPC stream.
- Binary resolution: `CANEDGE_MF4_BIN`, else `packages/canedge-cyphal/build/canedge-mf4`. Missing binary raises `FileNotFoundError` whose message contains `make -C packages/canedge-cyphal`.
- Accept only id `UnFinMF ` (eight bytes, trailing space) plus version `4.11    ` (eight bytes). One data group, record-id size 1, one `##DT` whose length field is 24. Payload is every byte after that header through EOF.
- Reject finalized `MDF` ids, `##DZ`, `##DL`, `##HL`, a second data group, local header time (`hd_time_flags` bit 0), virtual-channel slope other than 0, time scale other than the float64 of decimal `1e-6` or `1e-9`, `Dir` / `IDE` / `EDL` / `BRS` / `ESI` other than 0 or 1, `ErrorType` outside 0–5.
- Timestamp: scale `1e-6` means `start_time // 1000 + raw`. Scale `1e-9` means `(start_time + raw) // 1000`. Division toward zero. Column type `timestamp[us, UTC]`.
- Stable sort by `timestamp`, `channel` (raw text, so `CAN10` before `CAN2`), `id`, `data`. Tie-break is data-section order.
- Error frames use the six-row SocketCAN map in the spec. `dlc` 8, `err` true, the other flags false.
- Remote frames and LIN produce no rows. A file with no CAN data frames and no CAN error frames is a zero-row success.
- `cyphal-reassemble` does not change. No libparquet, no wheel, no bundled `_bin`.
- Hive paths, `convert` selection, and marker contents do not change.
- Commit messages follow Conventional Commits.

```cpp
#include "crc32.h"

uint32_t crc32_jamcrc(const uint8_t* data, size_t size) {
    uint32_t crc = 0xffffffffu;
    for (size_t i = 0; i < size; ++i) {
        crc ^= data[i];
        for (int bit = 0; bit < 8; ++bit) {
            uint32_t mask = -(crc & 1u);
            crc = (crc >> 1) ^ (0xedb88320u & mask);
        }
    }
    return crc;
}
```

```cpp
namespace {

std::vector<uint8_t> encode_literals(const std::vector<uint8_t>& raw) {
    heatshrink_encoder* enc = heatshrink_encoder_alloc(8, 4);
    std::vector<uint8_t> out;
    size_t sunk = 0;
    while (sunk < raw.size()) {
        size_t n = 0;
        heatshrink_encoder_sink(enc, const_cast<uint8_t*>(raw.data() + sunk), raw.size() - sunk, &n);
        sunk += n;
        for (;;) {
            uint8_t buf[256];
            size_t got = 0;
            auto poll = heatshrink_encoder_poll(enc, buf, sizeof buf, &got);
            out.insert(out.end(), buf, buf + got);
            if (poll == HSER_POLL_EMPTY) break;
        }
    }
    for (;;) {
        auto fin = heatshrink_encoder_finish(enc);
        uint8_t buf[256];
        size_t got = 0;
        heatshrink_encoder_poll(enc, buf, sizeof buf, &got);
        out.insert(out.end(), buf, buf + got);
        if (fin == HSER_FINISH_DONE) break;
    }
    heatshrink_encoder_free(enc);
    return out;
}

std::vector<uint8_t> wrap(const std::vector<uint8_t>& compressed) {
    std::vector<uint8_t> file;
    const char magic[] = "Generic File";
    file.insert(file.end(), magic, magic + 12);
    file.push_back(0x01);
    file.push_back(0x01);
    file.push_back(0x22);
    file.push_back(0x01);
    file.insert(file.end(), {0x06, 0xde, 0x1f, 0xe8});
    file.insert(file.end(), {0x00, 0x00, 0x00, 0x04});  // lookahead 4
    file.insert(file.end(), {0x00, 0x00, 0x01, 0x00});  // window 256
    file.insert(file.end(), compressed.begin(), compressed.end());
    uint32_t crc = crc32_jamcrc(compressed.data(), compressed.size());
    file.push_back(static_cast<uint8_t>(crc >> 24));
    file.push_back(static_cast<uint8_t>(crc >> 16));
    file.push_back(static_cast<uint8_t>(crc >> 8));
    file.push_back(static_cast<uint8_t>(crc));
    return file;
}

}  // namespace
```

`packages/canedge-cyphal/cpp/mfc.cpp`:

```cpp
#include "mfc.h"

#include <cstring>

#include "crc32.h"
#include "heatshrink_decoder.h"

namespace {

uint32_t be32(const uint8_t* p) {
    return (uint32_t(p[0]) << 24) | (uint32_t(p[1]) << 16) | (uint32_t(p[2]) << 8) | p[3];
}

std::string inflate(const uint8_t* in, size_t n, uint32_t lookahead, uint32_t window,
                    std::vector<uint8_t>& out) {
    if (window < 2 || (window & (window - 1)) != 0 || lookahead == 0 || lookahead > 15) {
        return "heatshrink window or lookahead is invalid";
    }
    uint8_t window_sz2 = 0;
    while ((uint32_t(1) << window_sz2) < window) ++window_sz2;
    heatshrink_decoder* dec = heatshrink_decoder_alloc(256, window_sz2, static_cast<uint8_t>(lookahead));
    if (dec == nullptr) return "heatshrink alloc failed";
    size_t sunk = 0;
    while (sunk < n) {
        size_t took = 0;
        if (heatshrink_decoder_sink(dec, const_cast<uint8_t*>(in + sunk), n - sunk, &took) < 0) {
            heatshrink_decoder_free(dec);
            return "heatshrink sink failed";
        }
        sunk += took;
        for (;;) {
            uint8_t buf[1024];
            size_t got = 0;
            auto poll = heatshrink_decoder_poll(dec, buf, sizeof buf, &got);
            out.insert(out.end(), buf, buf + got);
            if (poll == HSDR_POLL_EMPTY) break;
            if (poll != HSDR_POLL_MORE) {
                heatshrink_decoder_free(dec);
                return "heatshrink poll failed";
            }
        }
    }
    for (;;) {
        auto fin = heatshrink_decoder_finish(dec);
        uint8_t buf[1024];
        size_t got = 0;
        auto poll = heatshrink_decoder_poll(dec, buf, sizeof buf, &got);
        out.insert(out.end(), buf, buf + got);
        if (fin == HSDR_FINISH_DONE && poll == HSDR_POLL_EMPTY) break;
        if (fin < 0 || poll < 0) {
            heatshrink_decoder_free(dec);
            return "heatshrink finish failed";
        }
    }
    heatshrink_decoder_free(dec);
    return {};
}

}  // namespace

MfcResult unwrap_mfc(const uint8_t* data, size_t size) {
    MfcResult result;
    const char magic[] = "Generic File";
    if (size < 12 || std::memcmp(data, magic, 12) != 0) {
        result.bytes.assign(data, data + size);
        return result;
    }
    if (size < 32) {
        result.error = "MFC header is truncated";
        return result;
    }
    if (data[12] != 0x01 || data[13] != 0x01 || data[14] != 0x22 || data[15] != 0x01) {
        result.error = "MFC type is not heatshrink";
        return result;
    }
    uint32_t lookahead = be32(data + 20);
    uint32_t window = be32(data + 24);
    const uint8_t* compressed = data + 28;
    size_t compressed_size = size - 32;
    uint32_t expect = be32(data + size - 4);
    uint32_t got = crc32_jamcrc(compressed, compressed_size);
    if (expect != got) {
        result.error = "MFC checksum does not match";
        return result;
    }
    result.error = inflate(compressed, compressed_size, lookahead, window, result.bytes);
    if (!result.error.empty()) result.bytes.clear();
    return result;
}
```

- [ ] **Step 1: Write the builder and one failing test**

`tests/cpp/mdf_builder.hpp` builds, in one buffer:

1. 64-byte id: `UnFinMF `, `4.11    `, then zeros.
2. `##HD` with 6 links. Link 0 is the DG offset. `start_time` uint64, then tz/dst 0, `time_flags` byte `0x02`.
3. `##TX` name blocks (0 links, NUL-terminated text at byte 24 of the block).
4. `##CC` linear blocks (`cc_type` 1, `cc_val_count` 2, doubles at byte 24 of the CC data section, which starts after the 4 links). Timestamp CC values `0.0`, `1e-6`. Bus CC values `1.0`, `0.0`. IDE and Dir CC values `0.0`, `0.0`.
5. `##CN` blocks with 8 links: next, composition, tx name, 0, cc, data, 0, 0. Data section starts with `cn_type`, `cn_sync_type`, `cn_data_type`, `cn_bit_offset`, then uint32 `cn_byte_offset`, uint32 `cn_bit_count`.
6. `##CG` with 6 links: next 0, first CN, tx acq name. Data: `cg_record_id` 1, flags `0x0006`, `cg_data_bytes` 16.
7. `##DG` with 4 links: next 0, CG, DT. Data byte `dg_rec_id_size` 1.
8. `##DT` with 0 links and length 24, then the record bytes with no extra block header.

Every block's next address is `(offset + length + 7) & ~7`. Patch link fields after the targets exist. One record: id byte `1`, timestamp raw `1000` in the low 48 bits, CAN id `0x123` in the 11 ID bits, DLC `2`, data `aa bb 00 00 00 00 00 00`.

- [ ] **Step 3: Implement classic decode**

`cpp/decode.h` declares `Frame`, `DecodeResult`, and `decode_mf4` as in the Interfaces block.

`cpp/decode.cpp` does all of the following and nothing for VLSD or error frames yet (those record kinds are skipped in this task, which the builder does not emit):

- Reject when size < 64 or the first 16 bytes are not `UnFinMF 4.11    `.
- Walk blocks from offset 64. Block id is 4 bytes, length is uint64 at +8, link count is uint64 at +16, links follow. Next block is `(offset + length + 7) & ~7`. Stop at a non-`##` id or a length that runs past the buffer. The DT payload is not walked as blocks.
- Read `##HD` at offset 64. Fail if link 0 is 0. `start_time` is uint64 at the start of the HD data section. Fail if `hd_time_flags` (byte at data+12) has bit 0 set.
- Read that `##DG`. Fail if its next link is non-zero, if `dg_rec_id_size` is not 1, or if the data link is not a `##DT` with length 24.
- Walk the CG list. For each CG, read `cg_record_id`, `cg_flags`, `cg_data_bytes`, and the CN list including each composition list (CN link 1).
- TX text is the bytes at `block + 24 + 8 * link_count` up to the first NUL.
- A CN with `cn_type == 6` reads its CC (link 4). CC data starts after its links. Require `cc_type == 1` and `cc_val_count >= 2`. Doubles start 24 bytes into the CC data section (`8` bytes of counts plus two range doubles). Require the second double to be 0. The constant is the first double, converted with `static_cast` toward zero, and must be an integer in range for the field.
- A non-virtual field reads `nbits` little-endian: bit offset 0 is the least significant bit of `byte_offset`.
- A group whose composition root is named `CAN_DataFrame` appends one `Frame`. `channel` is `CAN` plus the decimal `BusChannel`. `timestamp_us = start_time / 1000 + raw` when the timestamp CC slope is the float64 of `1e-6`. Inline `DataBytes` (`cn_type == 0`) are `DataLength` bytes at that channel's byte offset, and `DataLength` must fit. Missing `EDL`, `BRS`, or `ESI` yields false. `rtr` and `err` are false. `tx` is `Dir == 1`.
- Any other group is ignored in this task.
- Sort with `std::stable_sort`. The comparator orders `timestamp_us`, then `channel`, then `id`, then `data`. Give each row its scan index and use that index when the four keys are equal.
- On failure, return `frames` empty and `error` set to one sentence. Do not return partial rows.

Add `cpp/decode.cpp` to `canedge_mf4_core` and `tests/cpp/test_decode.cpp` to `canedge_mf4_tests`.
